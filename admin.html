Première connexion sur cet appareil

Le site est hébergé sur GitHub Pages : l'admin publie directement dans le dépôt . Il faut un jeton GitHub limité à ce dépôt (à faire une seule fois par appareil).

  1. Ouvre github.com → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → .
  3. Permissions → Repository → Contents : Read and write. Rien d'autre.
  4. Expiration : la durée de ton choix (1 an max). Génère et colle-le ci-dessous.
