Première connexion sur cet appareil

Le site est hébergé sur GitHub Pages : l'admin publie directement dans le dépôt . Il faut un jeton GitHub limité à ce dépôt (à faire une seule fois par appareil).

  1. Ouvre github.com → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → .
  3. Permissions → Repository → Contents : Read and write. Rien d'autre.
  4. Expiration : la durée de ton choix (1 an max). Génère et colle-le ci-dessous.

Connecter le Google Sheet

Les inscrits restent dans ton Google Sheet : ils ne sont jamais publiés sur le site. L'admin les lit grâce à une clé secrète connue seulement de toi et du script Google.

  1. Google Sheet → Extensions → Apps Script : remplace tout le code par le fichier MERILIA - Google Apps Script (pre-save).gs → Enregistrer.
  2. ⚙️ Paramètres du projet → Propriétés du script : ajoute ADMIN_KEY avec une longue phrase secrète.
  3. Déployer → Gérer les déploiements → ✏️ sur le déploiement existant → Version : Nouvelle version → Déployer.
    ⚠️ Pas de « Nouveau déploiement », sinon l'URL change.
  4. Colle la même phrase secrète ci-dessous.
